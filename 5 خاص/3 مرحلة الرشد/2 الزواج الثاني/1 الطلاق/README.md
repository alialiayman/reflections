# الطلاق — الزواج الثاني

بعد حصولنا معًا على **الجنسية الأمريكية**، وسفرنا إلى **تركيا** و**اليونان**، أخذت الحياة مسارًا مختلفًا.

## ما حدث

انتهت هذه المرحلة **بالطلاق والانفصال عن الأولاد** — تجربة قاسية تركت أثرًا عميقًا.

## ما أريد أن أكمله

- ظروف الانفصال
- العلاقة بالأبناء بعد الطلاق
- كيف بدأت مرحلة جديدة بعد هذه النهاية
